# S01レビュー・検証記録（2026-11-13）

S01実装を`fac0e8f`としてコミットし、origin/mainへpush後、Claude Code（Sonnet）へレビューを依頼した。レビューはRead/Grep/Globによる読取専用とし、再現・比較実行・修正・テストはCodex側で実施した。初回はP0/P1なし、P2が1件、P3が7件。再レビューでは、初回の全指摘を修正または実測に基づく据え置きで処理済み、新たな具体的バグなし、P0/P1/P2の残件なしとの判定だった。

## 指摘と対応

| 指摘 | 対応・根拠 |
|---|---|
| P2-1：遠いブロックだけ保存すると間がNULになる | 指定Gforthでも4096バイトのファイルにNULの穴ができ、未初期化の1 LOADはUndefined wordとなった。空白へ変えると比較元と異なるため維持。マニュアルと実ファイルテストに、EOFの空白補完と既存の穴の違いを明記した。 |
| P3-1：ONLY ALSO EKEYSで戻れない | EKEYSをRootにも登録し、定数を取得する回帰テストを追加。 |
| P3-2：未完のESC列の後の特殊キーが未読文字を追い越す | ホストの未読バイトだけを取得するbuffered_key_fnを追加し、保留中の特殊キーより先に取得する。KEYで一部を消費した場合も順序を検証。対応コールバックのないホストではコアの未読バッファーを使用。 |
| P3-3：異常終了で未保存内容が失われる | 確定仕様どおり。-e／ソースの未捕捉エラー・シグナル終了も保証外であることを英日マニュアルへ明記。 |
| P3-4：端末EKEYのCtrl+Cがキー値3になる | 制御端末付きPTYでGforthがUser interruptになることを実測し、利用者が割込みへの変更を選択。SigmaはTHROW -28を返す。EKEY?と待機エラーも伝播し、リダイレクト入力のバイト3は値3を維持。GRAPHICS INKEYは変更しない。 |
| P3-5：読み取り専用blocks.fbを取得できない | Gforthでは0400のファイルを読めると実測。権限／読み取り専用エラーの場合に限りR/Oへfallbackし、書戻しは権限iorで拒否してdirtyを保持。無関係なopenエラーとfallback失敗では元のiorを保持。 |
| P3-6：サンプルのUPDATEが標準UPDATEを隠す | 確定した利用者定義優先の規則どおり。サンプルを勝手に改名せず、同名再定義警告も維持。 |
| P3-7：terminalUnreadのassert | 保存上限と「読んだ分だけ戻す」不変条件をコメントへ明記。現在の最大ESC先読み32バイトに対し保存領域は64バイト。 |

追加4点の最終確認でもClaude Codeは新たな具体的バグなしと判定した。再レビューの軽微な所見にも対応した。ESC／UTF-8の継続読込中に割込みが起きた場合は、それまでの入力列を戻してからエラーを伝播する。先読み済みの端末バイト3にも割込み処理を適用し、full-PTYの判定を末尾の比較結果まで確認する形へ強化した。

## 独自確認・補足

- macOSのPTYで`KEY . EKEY . BYE`へ`Aé\n`を送信すると、65の後で停止した。getcharの先読みとEKEYのread(0)が分離していたため、POSIXの端末バイト取得をread(0)へ統一した。修正後は65/233を取得。
- 初回EKEY?がrawモード再開マーカーだけでfalseを返す経路を修正し、到着済みキーを同じpollで取得する。
- WindowsのReadConsoleWで先読み済みのUTF-8とraw入力の残りバイトを、EKEY／KEY／ACCEPTの間で保持する経路を接続。Windows実機検証は別タスク607。
- GforthとSigmaはSGRマウス報告の先頭をともに27/91として返した。未知列を保持する規則に従い、独自の破棄処理は追加しない。
- `0 BLK !`はGforthでブロック0を入力に選択できたため、入力選択／REFILL／RESTORE-INPUTで0を許可した。初回の`0 LOAD`は引き続き-35。
- `>IN`の範囲外は既存のsourceCursorがclampするため、remainingSourceの範囲外アクセスは再現しなかった。ブロック中の`2000 >IN ! BL WORD`の回帰テストを追加した。
- S01前の`13eddba`を別の作業用コピーからビルドし、実際に保存したSIGIMG42を現在のLOAD-DICTIONARYで拒否することを確認。結果は-264、旧語は未登録、既存のKEEP=77は維持された。
