# 64バイト配置対照のレビュー対応

2026-11-16。[レビュー原文](VM_ALIGN64_CLAUDE_REVIEW.md)に対応した。コード修正の要求はなく、不採用・早期停止・一次CPU指標不変更は支持された。

1. PDB/計時版それぞれの基準・対照VAとmod64を表に追記。countedは元から整列済み、計時は非countedであることを明記した。VAはPE上で、実行時ASLR先は未観測。
2. 非countedの入口だけでなく全内部ラベルの位相も48バイトずれるため、入口だけの効果とはしない。
3. 初回未達を時点付きの記録へ修正し、追加ログ版での通過と区別した。
4. 追加ログ版を事前固定したプロトコル改定・別走行と明記。protocol生バイト列SHAとstart・各区間のUTC順序を照合して公開した。閾値・一次式不変更はプロトコルが不変という意味ではない。
5. 12,734.375msのA/A値を除外せず開示。中央値そのものは除外で変わり、通過可否が変わらないという限定で記した。単発異常の原因は未特定。
6. diagnostic_onlyラベルの由来とゲート用途、基準凍結物の過去ビルドコマンド参照、時計刻み・算術精度・区間CPUと生存期間CPUの違いを追記した。

任意提案のCPU0の割込み/DPC集中は、この調査では確認しておらず原因として採用しない。別コアのA/A、他のalign値、整列済みcountedだけの対照は今後の独立実験候補で、今回の結果へ遡って適用しない。すでに不採用の標準候補に33条件の測定を追加することは、今回の採否確定には不要と判断した。

レビューはRead/Grep/Glob計12回、明示パスは全てリポジトリ内。テスト・計測・ハッシュの独立再実行はしていない。開始時6入力をスナップショット保存し、受領後に本文を訂正した。
