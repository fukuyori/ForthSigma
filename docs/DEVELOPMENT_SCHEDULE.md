# FORTH/Σ Zig版 開発スケジュール

## 前提

- 開始日と週あたりの作業時間が未指定のため、週単位の相対計画とする。各週は「5作業日相当」の工程見積もりで、実際のカレンダー期間は作業可能時間に応じて調整する。
- 対象はZ80命令を実行しない、Zig製のポータブルなFORTH/Σ処理系。
- 初期目標は共通言語コアと端末入出力。CP/Mのファイル機能、PC-8001の編集・モニター機能、機種固有機械語は別機能として扱う。
- WindowsとUbuntu WSL上のLinuxで手動確認済み。Linuxは実機での動作も利用者が確認済み。macOSは当初、利用者の指示により実機確認を対象から省略していたが、2026-11-08 に macOS 27.2（Apple silicon）の実機で、`zig build test`、Homebrew の Tcl/Tk 9.1 での電卓、音の出力（利用者が耳で確認）、PKG の作成・署名・公証を確かめ、同日に、コマンドライン・引数の語・`SAVESYS`・xcharの語・日本語のファイル名・疑似端末での日本語の入力を確かめた（進捗の「macOSでの確認」）。

## マイルストーン

1. **M1: 互換性範囲を確定** — 第1週終了。各ワードの出典・対応状況・保留事項が確認できる。
2. **M2: コアを安定化** — 第2週終了。言語コアの自動回帰テストが通る。
3. **M3: ソースをファイルから実行** — 第4週終了。対話とファイル読み込みの両方で同じコアを使える。
4. **M4: クロスOS受け入れ** — 第5週終了。Windows・Linuxの実行記録がそろい、macOSを未確認として明記する。
5. **M5: 配布準備完了** — 第6週終了。ビルドと署名対応インストーラーのスクリプトが整う。

## 予定に含めない機能

- Z80命令エミュレーション、Z80の機械語をそのまま実行する機能
- PC-8001固有のモニター、画面（`SCREEN`）・プリンタ切り替え（`LPRINT` `CRT`）、カセット編集機能（誌面にグラフィックの語はない）
- CP/M固有のBDOS、DMA、ファイル制御ブロック
- 配布・公開、タグ作成、コミット、プッシュ

機種固有機能が必要になった場合は、共通コアに混ぜず、ホスト機能の拡張として別途見積もる。
