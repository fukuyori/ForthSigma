## 3. 実行手順・統計

測定・集計に使った最終コードは[main.zig](../bench-1386/main.zig)、[build.zig](../bench-1386/build.zig)、[build.ps1](../bench-1386/build.ps1)、[measure.py](../bench-1386/measure.py)、[analyze.py](../bench-1386/analyze.py)である。実行コマンドは次のとおりである。

```powershell

./bench-1386/build.ps1
python bench-1386/measure.py snapshot
python bench-1386/measure.py run
python bench-1386/analyze.py
python bench-1386/report.py
python bench-1386/finalize.py
```

build.ps1はA→B→A′の順に専用ハーネスをビルドし、AとBではハーネスの直後にCLIもビルドする。専用ビルドは `zig build --build-file bench-1386/build.zig -Dsource=<tree>/src -Dsuite=d -Dtarget=x86_64-windows --prefix <bench>/bin/<variant> -j1`、CLIは各ツリーで `zig build -Doptimize=ReleaseFast -Dtarget=x86_64-windows -Ddebug=false -Dstrip=true --prefix <bench>/cli/<variant> -j1` である。語群・容量は上記の既定値で共通である。

準備中、ハーネスが旧型情報APIのparamsを使っていたためBのビルドが失敗した。Zig同梱std/lang.zigのparam_typesを確認してハーネスだけを直し、Aを含めてビルドし直した。失敗ログはpreflight-build-B-failure.logに残した。正式標本を取得した後に負荷・ハーネス・実行体を変更していない。

| 負荷 | 内容 | 1標本の反復 |
|---|---|---|
| CALC | 加算・XOR・スタック操作・BEGIN/WHILEループ | 5,000,000回 |
| XT | 非builtin定数ONEのxtをEXECUTEして加算 | 2,000,000回 |
| DEFERRED | deferred語INC（1+）を実行 | 2,000,000回 |
| INTERPRET | SHORT 40 2 + DROPをinterpretLineで解釈 | 100,000行 |

各プロセスでCALC→XT→DEFERRED→INTERPRETを実行し、各負荷の最初の3回をウォームアップ、4回目を採用した。結果のスタック・値、XTのexecute Op、定数とdeferredの語種を検証した。計60組、各組でA/B/A′を連続実行した。順序はA-B-A′、B-A′-A、A′-A-B、A′-B-A、B-A-A′、A-A′-Bを10周期である。正式負荷プロセス数は180、採用標本は各対象・負荷60個である。

QPC周波数は[10000000] Hz、1 tickは[100.0] nsである。ns列はtick差の整数換算値であり、1 nsの実分解能を意味しない。初期化・検証・CSV出力は計測外である。lookupを含む実行API呼出しを計測した。

p95はnearest-rank（60標本では昇順57番目）である。主比較は分布の中央値同士の比であり、対応比の中央値とは区別する。95%区間は組を対応付きで100,000回再標本化するpercentile bootstrap、固定seed 1386である。中央値比とp95比の双方を求めた。符号検定は対応差の正確両側検定で、ゼロ差を除外する。補助として対応比中央値の二項順序統計区間も示す。多重比較補正はせず、負荷ごとの探索的比較である。区間は今回の固定実行体・実行環境の標本に基づき、別の配置やCPUを含む保証ではない。時系列の依存を明示的にモデル化した区間でもない。

固定した分類規則は、中央値比95%区間の上端≤1.01かつp95比95%区間の上端≤1.02なら「目安内」、いずれかの下端が閾値を超えれば「目安外」、それ以外は「判定不能」である。ただし中央値比区間の幅が0.01を超えるときは1%を識別する精度不足として「判定不能」を優先する。点推定だけの照合も併記する。負荷間の平均は計算しない。

分類の読み方には注意が必要である。B/AのCALC・XT・DEFERREDは中央値比95%区間全体が1未満であり、今回の標本では短縮する向きが明確である。それでも固定規則の「区間幅が0.01を超えたら判定不能を優先」により、1%単位の精度を満たさない分類となった。これは差の向きも分からないという意味ではない。INTERPRETのB/A′も中央値比95%区間が[1.016170, 1.030287]であり、下端が1.01を超えている。一方、幅が0.014117であるため固定規則を優先して「判定不能」とした。閾値超過を示す中央値の材料を分類名だけで隠さず、最終判断に提示する。p95比区間は[1.002077, 1.048506]であり、1.02をまたぐ。

これらは固定条件の判断目安への照合であり、最終合否はレモンが決める。1%の区別ができない組合せは分類を「判定不能」として残した。p95は60標本の上側少数点に依存するため、中央値と同じ精度の値とは扱わない。観測最大値を保証上限と呼ばず、平均による負荷間の相殺もしない。
