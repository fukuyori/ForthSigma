# グラフィックモード

FORTH/Sigmaには、BASICの `SCREEN 1` のような番号付きの画面モードはありません。プログラムはメモリ上の1枚の画像（大きさは自由）に描き、`SHOW` でどこに表示するかと、何色で表示するかを別々に選びます。このマニュアルでは、これらの選び方を説明します。描画の語そのものは、[グラフィックスとサウンドのマニュアル](GRAPHICS_AND_SOUND.ja.md)を見てください。

ここで扱う語はすべて `GRAPHICS` 語彙にあります。

```forth
REQUIRE-GRAPHICS  ALSO GRAPHICS
```

## 3つの選択

| 選ぶもの | 語 | 初めの状態 |
| --- | --- | --- |
| 画像の大きさ | `GFX-INIT` ( w h -- ) | なし（`GFX-INIT` の前は画像がない） |
| `SHOW` の表示先 | `DISPLAY-TERMINAL`、`DISPLAY-WINDOW`、`DISPLAY-TK`。端末では `TERMINAL-BLOCKS` と `TERMINAL-SIXEL` | ホストにウィンドウがあれば（Windows）ウィンドウ。なければ、デスクトップで `wish` が起動できればTkのウィンドウ（Linux、macOS）。それもだめなら端末に半角ブロック |
| 色数 | `DISPLAY-COLORS` ( n -- )、`DITHER` ( flag -- ) | フルカラー、ディザなし |

3つは互いに独立していて、どの大きさの画像も、どの表示先・どの色数とも組み合わせられます。変わるのは表示のしかただけです。画像そのものは常に24ビットのフルカラーで、`SAVE-PPM`・`SAVE-BMP`・`SAVE-PNG` は何を選んでいてもフルカラーで保存します。

## 画像

`GFX-INIT` ( w h -- ) は新しい黒い画像を作ります。幅・高さは各1〜8192画素、画像は64 MiBまでです（1画素4バイトなので、正方形なら4096×4096まで）。画像は一度に1枚で、もう一度 `GFX-INIT` すると置き換わります。座標は左上が 0 0 です。

大きさは、320×200や640×400のように昔のパソコンに合わせても、プログラムに合わせてもかまいません。小さな画像は、後で説明する `WINDOW-SIZE` で大きく表示できます。

## 表示先

| モード | 選び方 | 使える環境 | 表示のしかた |
| --- | --- | --- | --- |
| 端末、半角ブロック | `DISPLAY-TERMINAL TERMINAL-BLOCKS` | すべてのOS | 1文字で上下2画素を、24ビット色のエスケープで表示します。 |
| 端末、Sixel | `DISPLAY-TERMINAL TERMINAL-SIXEL` | Sixelに対応した端末 | 本物の画素で表示します。 |
| ウィンドウ | `DISPLAY-WINDOW` | Windows | Sigma自身のウィンドウに表示します。 |
| Tkのウィンドウ | `DISPLAY-TK` | Tcl/Tk（`wish`）が入っていれば、すべてのOS | Tkのウィンドウ `.` に、画像をPNGで送って表示します。 |

`DISPLAY-TERMINAL`・`DISPLAY-WINDOW`・`DISPLAY-TK` のどれかを使うまでは、`SHOW` は、ホストにウィンドウがあればウィンドウに表示します。ホストにウィンドウがあるかどうかは `GFX-WINDOW?` ( -- flag ) でわかります。ウィンドウのないホストで `DISPLAY-WINDOW` を使うと `HOST FUNCTION UNAVAILABLE !` になります。LinuxとmacOSにはまだウィンドウがないので、Sigmaがデスクトップで動いていれば、最初の `SHOW` がTkのウィンドウを試します。デスクトップかどうかは、環境変数 `DISPLAY` か `WAYLAND_DISPLAY`（X11、Wayland）、または `__CFBundleIdentifier`（macOSの端末のアプリ。SSHでは付きません）があるかで決めます。`wish` が起動して画像を表示できれば、それからは `DISPLAY-TK` と同じくTkのウィンドウに表示します。できなければ（デスクトップでない、Tcl/Tkがない）、`DISPLAY-TERMINAL` と同じく端末に表示します。そのため、Tcl/Tkを入れたLinuxやmacOSのデスクトップでは、`sigma examples/hopper.fs` でウィンドウが開きます。そこで端末に表示したいプログラムは `DISPLAY-TERMINAL` を使います。

`TERMINAL-BLOCKS` と `TERMINAL-SIXEL` は、端末での表示のしかたを選ぶだけで、それ自体では `SHOW` の表示先を端末にしません。既定は半角ブロックです。

### 端末、半角ブロック

- ほとんどの端末で表示できます（Windows Terminal と Windows のコンソール、xterm、GNOME Terminal など）。
- 画像が端末より大きいときは、縦横比を保って端末に収まるように縮め、縮めた1画素は元の画素の平均の色にします。1行はプロンプトのために残します。小さい画像は拡大しません。1文字が幅1画素・高さ2画素です。
- 出力が端末でないとき（パイプやファイル）は、80桁24行とみなします。
- Windowsでは、半角ブロックを書いている間だけコンソールのコードページをUTF-8にして、終わったら元に戻します。

### 端末、Sixel

- Sixelに対応していない端末では、乱れた文字が出るか、何も表示されないことがあります。
- 画像は端末の画素の大きさ（端末が知らせないときは1文字10×20画素とみなします）に収まるように縮め、幅は4096画素までです。小さい画像は拡大しません。
- フルカラーでは、6×6×6の216色で表示します。`DISPLAY-COLORS` で色数を決めたときは、その色を使います。

### ウィンドウ（Windows）

- ウィンドウは専用のスレッドで動くので、Forthが入力を待っている間も、動かす・大きさを変える・閉じることができます。キー入力はコンソールのままで、ウィンドウで押したキーも `INKEY` に届きます。
- `SHOW` のたびに今の画像を描き直し、画像の大きさか `WINDOW-SIZE` の大きさが変わればウィンドウの大きさも合わせます。`WINDOW-SIZE` がなければ、1600×1200画素より大きい画像は縮めて表示します。
- ウィンドウの大きさを変えると、画像は縦横の比を保って描き直し、余りは黒にします。
- 閉じたウィンドウは、次の `SHOW` で開き直します。

### Tkのウィンドウ

- SigmaはTcl/Tkのプログラム（`wish`）を、最初に必要になったときに起動します。どこから探すかは、[グラフィックスとサウンドのマニュアル](GRAPHICS_AND_SOUND.ja.md)の「Tcl/Tk」を見てください。
- `SHOW` のたびに画像全体をPNGで送るので、大きな画像は更新が遅くなります。
- `WINDOW-SIZE` があれば、画像は入る最大の整数倍で表示し（Tkは整数倍でしか拡大しないため）、入らなければ整数分の1に縮めます。ウィンドウの大きさを変えたときも同じです。
- ウィンドウを閉じると、次の `SHOW` まで隠れます。

### 各モードでのキーとマウス

`INKEY` は、どのモードでも端末のキーを読み、ウィンドウとTkのウィンドウでは、そのウィンドウのキーも加わります。

| モード | キー（`INKEY`、`KEY-HELD?`） | `MOUSE` |
| --- | --- | --- |
| 端末 | 端末のキー | `MOUSE-ON` の後、その後の最初の `SHOW` から |
| ウィンドウ | 端末とウィンドウのキー | ウィンドウは常に知らせます。伸び縮みした画像の、マウスの下の画素を返します |
| Tkのウィンドウ | 端末とTkのウィンドウのキー | Tkのウィンドウでのマウス |

詳しくは、[グラフィックスとサウンドのマニュアル](GRAPHICS_AND_SOUND.ja.md)の「キー、マウス、アニメーション」を見てください。

## 色数

`DISPLAY-COLORS` ( n -- ) は `SHOW` の色数を決めます。色数の少ない端末や、昔のパソコンのような見た目のためです。端末（半角ブロックとSixel）、ウィンドウ、Tkのウィンドウのすべてに効きます。

| n | 色 |
| --- | --- |
| 0 | フルカラー（既定）。Sixelは216色です。 |
| 2 | 明るさによる白黒。 |
| 16 | ANSIの16色（エスケープの30〜37と90〜97）。近い色はxtermの既定の見え方で選ぶので、端末によっては違って見えます。 |
| 256 | xtermの256色のうち16〜255番（6×6×6の色と24段階の灰色。`ESC [ 38 ; 5 ; n m`）。Sixelも同じ240色を使います。 |

ほかの値は `NUMBER ERROR !` になり、色数は元のままです。

`DITHER` ( flag -- ) は、色数を減らすときに、4×4のBayerの模様で色を混ぜる（真）か、いちばん近い色にする（偽、既定）かを決めます。模様は位置で決まるので、アニメーションでもちらつきません。フルカラーではディザをかけません。

## 表示の大きさ

`WINDOW-SIZE` ( w h -- ) は、次の `SHOW` から、ウィンドウとTkのウィンドウで、画像を w×h 画素の領域に表示します。各辺は1〜8192で、0 0（既定）なら画像と同じ大きさです。画像は縦横の比を保って入る最大の大きさで中央に描き、余りは黒にします。画像そのものと端末への表示は変えません。

## 例

160×120の画像を、ウィンドウで1画素を4×4にして表示します。

```forth
REQUIRE-GRAPHICS  ALSO GRAPHICS
160 120 GFX-INIT  640 480 WINDOW-SIZE
255 255 0 COLOR  80 60 40 CIRCLE
SHOW
```

続けて、同じ画像を端末に16色、ディザ付きで表示します。

```forth
DISPLAY-TERMINAL  TERMINAL-BLOCKS
16 DISPLAY-COLORS  TRUE DITHER
SHOW
```

Sixelで白黒にして表示し、フルカラーに戻します。

```forth
TERMINAL-SIXEL  2 DISPLAY-COLORS  SHOW
0 DISPLAY-COLORS  FALSE DITHER
```

Tkのウィンドウに表示します（LinuxとmacOSでも使えます）。

```forth
DISPLAY-TK  SHOW
```

## 下の層の語

ここまでの語は、グラフィックスのライブラリ（`src/graphics/graphics.fs`）のForthの定義なので、`SEE` で中身を見られます。`SHOW` は `GFX-COLOR-MODE` ( n flag -- ) で色数をホストに渡してから、`GFX-SHOW-BLOCKS`・`GFX-SHOW-SIXEL`・`GFX-SHOW-WINDOW`・`GFX-SHOW-TK` のどれかを呼びます。これらを直接呼ぶプログラムは、色数を自分で `GFX-COLOR-MODE` で決めます。

## 保存

画像は辞書の一部ではありません。`SAVE` と `SAVESYS` は画素を保存しないので、保存したプログラムは起動後に `GFX-INIT` で画像を作り、表示先・色数・`WINDOW-SIZE` もそこで選びます。
