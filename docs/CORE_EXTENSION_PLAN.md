## 語群（2026-11-18、利用者の決定）

拡張機能は、ビルドのときに選んで切り離せなければならない。サウンド、グラフィックス、拡張モジュールの3つに分けて作る。ここまでが決定である。3つを公開する語の上で互いに依存させないこと、オプションの名前、読み込み方、時計の語の置き場所は未決で、[共通の取り決め](ASYNC_COMMON_RULES.md)の8節に案がある。

| 語群 | オプション | 項目 |
|---|---|---|
| サウンド | `audio`（既存） | 9、10 |
| グラフィックス | `graphics`（既存） | 8、11、12 |
| 拡張モジュール | 新しいオプションを1つ足す | 1〜7、時計の語 |

## 進める順序

| 段階 | 項目 | 理由と、できるようになること |
|---|---|---|
| 0 | 共通の取り決め（900） | 待機・期限・中断、キュー、資源の持ち主、実行制御の仕様を先に決める。A、B、Cがこれに依存する |
| A | 1、2、時計の語、8 | 全画面の表示とキー入力ができる。8は、キューの扱いを2とそろえる |
| B | 3、5、9 | 外部コマンドの出力を受けながら入力を扱える。9は、書く語の形を3とそろえる。9が依存するのは900だけで、3の実装は待たない |
| C | 4、6、7、10、11、12 | 4、6、11、12はほかの項目から独立している。7は仕様を段階0で決めてから実装する。10は、Forthで書いた音源の速度を測るまで本体の作業を始めない。12は、Forthで書いたエミュレータの速度を測ってから決める |

tqueの依存は次のとおり。637、638、639、652、997、998、999は900に依存する。643は639にも、999は998にも依存する。

## 作業の制約

2026-11-18の時点で、ソースコードはLinuxのウィンドウの作業中である。その作業が終わるまで、この拡張のためのソースの変更とビルドは行わない（利用者の指示）。進めるのは、仕様の文書、tqueの整理、読み取り専用のレビューである。
