# 613 詳細設計の判断記録

作成日：2026-11-19

この文書は既存の利用者決定、新しい設計提案、レビューの評価を区別して記録する。実装前の提案を利用者決定・検証済み仕様へ格上げしない。

## 既存の決定

3語群の分割、652のデバッグ専用、通常実行ループを変えない方針、物理キーの別経路、Windows入力レコードの維持、部分書込み、PCMの独立性、音源・描画補助を実測で判断する方針は維持する。通常実行ループの方針は、命令ごとの定期取消し確認を通常経路へ加えないことを必須とする意味である。機械語不変は必須とせず、入口判定・State配置・回復判定・サイズは改良後の差分を見て利用者が個別に判断する（2026-11-24）。根拠は詳細設計1節と各計画の決定事項、および下記の利用者決定。

## 2026-11-19：1056・1036での具体化

[語群基盤の設計](EXTENSION_GROUP_DESIGN.md)のとおり、extension既定true、REQUIRE-EXTENSION、独立したEXTENSION語彙を採用した。HOST-OSは従来の数値案を文字列`( -- c-addr u )`へ具体化し、builtin.os.tagによるOS系列を毎回専用の論理領域へコピーする。イメージは既存magicのまま、除外した全語群の追加builtinと直接builtin Opを事前に拒否する。これは以前のaudio/graphicsイメージ読込みに対する制限の追加である。最終検証結果は実装記録、レビューの評価・対応は別文書へ残す。Mac実機1065は未完了を保ち、利用者指示により1056は完了済み1064を先行条件とした。
