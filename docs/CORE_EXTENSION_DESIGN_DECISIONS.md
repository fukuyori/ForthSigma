# 613 詳細設計の判断記録

作成日：2026-11-19

この文書は既存の利用者決定、新しい設計提案、レビューの評価を区別して記録する。実装前の提案を利用者決定・検証済み仕様へ格上げしない。

## 既存の決定

3語群の分割、652のデバッグ専用、通常実行ループを変えない方針、物理キーの別経路、Windows入力レコードの維持、部分書込み、PCMの独立性、音源・描画補助を実測で判断する方針は維持する。根拠は詳細設計1節と各計画の決定事項。

## レビュー評価の取扱い

Claude Codeの結果は別文書へ保存し、各指摘について設計への反映、提案の修正、実装時の検証ゲートのいずれかを対応記録へ記す。レビュー完了は方式採用や実装完了を意味しない。
