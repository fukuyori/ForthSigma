# 計時診断・実例頻度レビューへの対応

[Claude Codeレビュー原文](VM_WORKLOAD_CLAUDE_REVIEW.md)はRead/Grepによる静的確認で、重大事項なし。旧40標本表はレビューで再計算した対象ではない。

1. reset検証の不足を確認。最初のプローブはラベルと出力の検証に限定すると訂正し、reset前7回・後10回の追加プローブを実行した。resetなし各17回、あり各10回を確認してデータとスクリプトを保存した。
2. 全PC合計一致を独立した検証と呼ばず、出力/解析の自己整合確認と明記。2回一致は決定性で、系統誤りを否定しないと追記した。
3. 一次CPU/API差の一致を自己整合と明記。新診断12標本と4warmupで主スレッドCPU照合も実施し差0を保存した。集計スクリプトを追加した。どちらもCPU会計精度を保証しない。

連続セッション内の2系列であること、絶対範囲が縮んだわけではないこと、15.625 ms刻みと経過時間差の観察を追記した。レビューの「経過時間約5〜6%超過」は全条件には当てはまらず、実際の中央値比3.383〜6.080%を記録した。原因を断定していない。

plain_calls変更はコード確認であり全生成コードの同一性を検査していない。SYNONYM/DEFER等のラベル未分離、終了行がcolon語なら計数される限界、名称重複警告、計測版ファイル別ハッシュを追記した。表のメモリー5語は全メモリー操作ではない。

#792の調査順は既定の小規模候補の順を維持したもので、全入力の頻度首位や全候補の効果順位を確定した判断ではない。#806でlocal_fetch/call等も比較する。局所案の後回しは今回の限定入力における判断で、一般的な不採用ではない。

本体未変更・候補の新たな速度比較なし。再試行なしという報告はローカル成果物だけによる独立証明とは扱わない。
