## 測定上の注意(Low)
1. **NTIME は壁時計の時刻です。** help_text.zig に「wall time can jump」とあります。測定中に時刻が補正されると値がずれ、逆方向に飛ぶと `assert v[43]>0` で全体が止まります。
2. **CPUTIME はマイクロ秒単位です。** Windows では粒度が粗い可能性があります(※推測です)。scope に書かれている quantized の注記のとおりです。
3. **コンパクションは毎回 0 件の MOVE になります。** count が常に偶数で、全件処理した後にコンパクトされるためです。「compaction included」という記述は正しいですが、残りがある MOVE のコストは含まれていません。
4. **`ZX-SLOW` 経路は測定対象外です。** 測るのは高速経路だけです。
5. **stale ファイルの扱い:** `pcm.bin` と `run.fs` は回をまたいで同じパスを使います。書き込みに失敗すると THROW して検出されます。SUM の照合もあるので実害はない見込みですが、毎回 unlink すればより確実です。
6. **timeout 60 秒:** 測る回は WORK を 2 回実行します。`128k_period_zero` などがこの時間に収まるかは未確認です。
7. **scope 文字列の空白抜け:** `"39 semantic states and2 queue counters"` で空白が抜けています(表示だけの問題)。
8. **CPU-ALL 2 回分の時間:** 壁時計の測定値に CPUTIME 2 回分のシステムコールが入ります(ごく小さい)。
