## 前回の M1（feedback の検証）：解消

`verify-snes-dsp-audio.py:236-241` を、`Model` と同じ式で計算しました。

- **入力**：FIR tap0 = 127、tap7 = 64、`ehist[1][0]` = -16384、`word(0)` = -1234
- **ch0 の FIR**：-32512 + (-617) = -33129 で、clamp されて **fir = -32768** になります。
- **feedback**：-32768 × -128 // 128 = 32768。これを `signed16` にすると -32768 で、書き戻される word は **`0x8000`（32768）** です。
  - flag 0 と 64：32768 が書かれます。初期値の 64302（`0xFB2E`）とは違う値です。
  - flag 32：64302 のまま残ります。
  - そのため、**書き込みと書き込み禁止を区別できています**。
- **折り返しの代わりに clamp で実装した場合**：32767 & ~1 = 32766 になり、32768 と違うので検出できます。
- **EVOL の折り返し**：EVOL = -128 なので、left は -32768 です。clamp なら 32767 になります。flag 64 のときは 0 になります。どれも `SNAP` の left で区別できます。
