## 1. verify-alpha-visual.py と ALPHA_VISUAL_VALIDATION.md

**結論: High・Medium はありません。**

照合で偽陽性が出ないかを、次の点から確認しました。

- **全画素を完全一致で比べている**: `verify-alpha-visual.py:61` は、PPMのRGB全体と、Pythonで計算した期待値のバイト列を `==` で比べています。許容誤差もサンプリングもありません。614,400 = 640×320×3 で、文書 `:15` の数と合っています。
- **期待値をSigmaから取っていない**: 期待値は、市松模様(`:37`)に `(c*a+d*(255-a)+127)//255` を5回、配置の順に重ねて作っています(`:39-45`)。Sigmaの出力は使っていません。市松模様の判定 `(x//16+y//16)%2` で奇数のとき 48 になる点は、Forth側の `+ 1 AND IF $303030` と一致しています。
- **alphaが効いていなければ失敗する**: 完全透明の画素にはマゼンタのRGBが入っています(`:30, :33`)。alphaが保持されない、あるいはRGBが漏れる場合は、`:61` で一致しなくなります。
- **配置がキャンバス内に収まる**: 配置は全部キャンバスの中です。いちばん外側は x=571、y=259 です。煙3枚は互いに重なり、円2つは重なりません(中心間は約127、半径は最大49)。文書 `:13` の「煙はずらして重ね、円は別の2か所」と合っています。
- **alphaの範囲**: 煙は最大175で、不透明にはなりません。円は内側が255です。0・中間値・255のすべてが照合に含まれます。
- **出力の解釈**: ヘッダは `P6` / `640 320` / `255` と固定値で比べています(`:59`)。終了コード0、stderrが空、stdoutが `0`(DEPTH)であることもassertしています(`:55`)。`-O` での実行は拒否します(`:16-17`)。
- **文書の書き方**: 計算式は `:16` とコードで同じです。適用範囲も `:17, :21-23` で限定されています。不透明な背景への合成だけで、モニター上の表示やTkでの表示は対象外であること、補間は1309に残すことが書かれています。ご説明の内容と食い違いはありません。
