# 1056・1036 レビューの判断と対応

2026-11-19。[設計レビュー原文](1056-design.md)と[依頼文](1056-requests.md)を分離する。以下はロクの判断・実装結果であり、利用者の直接決定とClaude Codeの評価は同一視しない。

## 設計レビュー

セッション`4c61ae7d-299a-4da2-b4ea-4a23b263181d`。Read/Glob/Grepのみ。ビルドと実行は行っていない。

| 指摘 | 判断と対応 |
|---|---|
| D01 除外イメージはABIだけで区別できない | 採用。ABI更新は旧Builtin表との差を検出する。機能の有無は追加builtinと直接builtin Opの内容を別途検査し、全語群へ適用する。以前audio/graphics除外でも読めたイメージを拒否する変更として明記する |
| D02 保存されたOS名が古くなる | 採用。呼ぶたびに8バイトの論理領域へ書き直す。次の呼出しかイメージ復元まで借用可、書換え禁止。単体試験で保存前に別値を詰めて復元後の再取得を確認 |
| D03 記録セルは$TMP領域を避ける | 採用。0xdc0が語彙、0xdc8が文字列。元案から両者の順番は逆だが、領域の非重複はcomptime検査する |
| D04 appendの一覧と固定長 | 採用。library_groupsの一つのtupleを両経路が使用し、配列長も一覧から決める |
| D05 無効時のparser分岐 | 採用。有効時だけ分岐し、無効時は通常のUnknownWord（-13）と同名の利用者定義の経路を使う。既存audio/graphicsの専用エラーは変更しない |
| D06 OS取得元 | comptimeのbuiltin.os.tagを採用。OSサービスは不要でfreestandingはunknown。Writerの接続漏れを避ける |
| D07 数値案と依存関係の差分 | 採用。文字列案へ具体化した判断を設計に記録。1056は完了済み1064を待ち、900とMac実機1065は未完了を保つ。外部Gforthへの照合は今回行わず、Sigma独自語として記載する |
| D08 HELP・ライブラリ・除外 | 採用。共通の除外表、条件付きの組込みForthソース、HELPと全語リファレンスへ反映し、8構成と代表除外構成で照合する |

HOST-OSの名前と文字列仕様、extension既定trueは、この具体案とClaude Codeとの設計検討に基づく実装判断である。将来の時計API・タスク実行方式は今回の採用に含まない。

## 実装レビュー

[原文](1056-implementation.md)。固定コピー`.work/1056-review/implementation/`、セッション`d4e077c1-e5a3-4745-a607-79f2f49f257a`、約304秒。以下は原文の番号にIを付けた対応。

| 指摘 | 判断と対応 |
|---|---|
| I01 graphics除外の従来試験 | 実際に試験で失敗を確認し修正。wire codecから機能検査を復元preflightへ移し、保存は構造検査、読込みは機能検査と分ける。graphicsの旧試験を3経路の拒否と辞書不変へ変更。extension/audio/files/debugの追加builtinと直接Opも3経路で検証する |
| I02 基本辞書の呼出しとの差 | 推奨(a)を採用。追加builtinと直接Opだけを事前拒否し、予約された基本辞書への通常の呼出しは従来どおり実行時-261。生xtデータとは別にこの制約を明記し、files除外で保存・復元と実行時拒否を試験 |
| I03 Stateの不整合な範囲 | word/codeの範囲をスライス前に検査する。壊れたsourceの追加をInvalidImageで拒否し、対象の語数不変を試験 |
| I04 名前とOS系列 | HOST-OSは維持。target OS family、Wine上のWindows版はwindows、未知の文字列をunknown扱いする方針を記載。Gforthの推測の照合は行わない |
| I05 HELPの一覧 | extensionのdefinitions/library_wordsを走査し、読込み後の説明判定にも明示的に追加 |
| I06 メモリー配置 | comptimeの領域重複検査を追加済み。原文は変更せず採用仕様へ実際の番地を記録 |
| I07 任意Forth実行の巻戻し | 現在のコメントのみのライブラリには該当しない。辞書・検索設定の巻戻しであり任意のスタック/メモリー副作用を取り消さないことを明記。ソースファイル名の欄は再利用される既存契約 |

修正済みの固定コピー`.work/1056-review/followup/`を読み取り専用で追加確認した。[原文](1056-followup.md)、セッション`09df8c8b-5e81-4846-9b9e-e89461d4b83b`、約166秒。読んだ範囲では新たな高・中の問題は見つからず、I01・I03・I05・I06の修正が確認された。実行試験と文書全体の承認ではない。

追加の低い4指摘には次のとおり対応した。これらの補強は追加確認の後に行い、回帰試験で検証する。

- F01：既定構成では拒否試験を明示的なskipとし、除外マトリクスで実行する。辞書不変の比較を語数・data_hereに加え、names_used・code_count・heapTop・wordlistCountへ拡大した。
- F02：SAVEはwire形式を確認し、機能可否は読込み時に判定する契約を設計へ明記済み。
- F03：HELPへ未知の値をunknownと同じく扱う説明を追加し、日本語リファレンスも更新した。
- F04：float局所変数の+TOやFLITERALの直接Opも事前拒否、F+の普通の呼出しは実行時拒否という具体例を設計へ追加した。
