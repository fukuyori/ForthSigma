## 実装レビューへの対応

[実装レビュー原文](640-implementation-claude-review.md)は境界エンジンの高・中の不具合なし、試験自動化と文書に中2件を報告した。製品の実行承認や全環境での合格を意味しない。

- M1：公式853ケースをcore単体へ組み込み、通常の`zig build test`で走査エンジンを検証する。公開語3,096項目の独立scriptも保持。生成再現性・固定SHA検査を`check-docs.py`へ接続する。
- M2：データREADMEを実装済み手順へ更新し日本語版を追加。試験scriptの英日READMEへ実行方法を記載した。これらの一部はレビュー中に更新済みだったため、指摘時点の記述と区別する。
- 低い補足：公開語scriptにも公式fixtureのSHA検査を追加。長さは足りるが継続バイトが不正な2列、除外時の辞書lookupの試験を追加。入力SHAはmanifestを正本とし生成表への重複記載はしない。

## 試験基盤の限定再レビュー

[限定再レビュー原文](640-followup-claude-review.md)では試験自動化M1を対応済みと評価し、英語データREADMEに通常試験と製品への非埋込みの説明がない点を中1件とした。同じ説明を英語へ追加した。

補足のlookup懸念は検索順序に依存しないよう、全辞書のwordNameも走査する試験へ補強した。公式試験パーサーの固定バッファにも書込み前の上限検査を追加した。生成器はmanifestのfiles全件を走査するためGraphemeBreakTestのSHAも検査する。限定レビューが未確認とした試験READMEの英日記載は実ファイルで確認した。
