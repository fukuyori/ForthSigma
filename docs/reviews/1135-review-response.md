# 1135 DMCモデルと対象一覧：レビュー評価・採否

2026-11-20。[設計原文](1135-design-claude-review.md)、[実装原文](1135-implementation-claude-review.md)、[最終原文](1135-final-claude-review.md)を分ける。ClaudeはRead/Grep/Globだけで、コマンド・試験を実行していない。実行結果は[NES DMCの記録](../NES_DMC_FORTH.md)へ分ける。最終レビューはHigh/Mediumなし、M1〜M4解決済み。

## 対象範囲と完了条件

設計指摘を採用し、1139を上位計画8機種の先行照合、1140を依存付き最終採否へ分けた。1140はNES1132/SID1136/Paula1137/ST1138/先行照合1139に依存する。照合で不足が見つかれば機種別タスクと1140の依存へ追加し、均等平均の分母が増える場合を明記した。NES以外を完了・対象外にしていない。最終レビュー時点はDMC作業中で999=21%、NES完了後は999=28%になった。レビューの21%はその時点の記録として保つ。

## DMC設計

- rate index13=84、開始番地/長さ/FFFF→8000、readerと1byte buffer、last fetch時のloop/IRQ、statusのclearの違い、rate変更時にtimerを戻さないことを採用。
- 最初の依頼文の「±2 clipped」は正確でなかった。実装は最初から範囲を出る場合に変化しない規則であり、126/125/1/2の手計算試験と仕様の文言を揃えた。
- NA-MEM!は現在時刻に反映し、RESETでもmapを消さないことを明記。zero DMA-delayのモデル規則を資料の実機DMAと区別し、CPU/PPU・bus競合・power-on phase・PALを範囲外として記録する。
- full LUTを任意精度のPythonと比較し、最大8469+24297=32766を観測。中間積は倍長UM*/UM/MODで処理し、d=0の旧4声との一致を保つ。

## 実装指摘M1〜M4

- M1採用：4声のPCMを新しいForth/Pythonの相互比較だけにせず、旧1134の固定SHA c63131af…d94755も検査する。旧測定の4構成の結果が当時のJSONと等しく、保存した全ソース本文が当時のLF SHA256に一致することも実行して確認した。
- M2採用：rate15の後に同じ15を書いていた場面を0への変更に直し、timer26/period213→cycle55で0→56で213という手計算を追加した。wrap27596/27597と、remainingが残ると再有効化しても再開しない手計算も追加。
- M3採用：最新のtask snapshot、全体計画、対象一覧、引継ぎで1139/1140の役割・依存・分母を揃えた。作業中/完了後を区別し、歴史的な25%/6枝や21%を現在値と混同しない。
- M4採用：全process時間にLUTの初期化と32KBのpattern生成を含み、旧1134と直接比較できないことを記載。debug/graphics/extension除外構成でも表を読み込んで実行した結果を記録した。

8kHz直接DACは描画中のenqueueと領域回収をtimed regionへ含めた。自作pattern以外のROM/音声/他エミュレーターコードを使用していない。実聴・Macの新しい例・ROM互換とAPU単独のモデル測定を分ける。
