2. **親プロセスの SIGINT ガード**:何もしないハンドラーを登録しているので、POSIX では exec 時に既定動作に戻り、子に `SIG_IGN` は引き継がれません。子の出力は `bufsize=1` で1行ずつ表示・記録しています。標準入力は子に引き継がれます。終了時は `finally` で元のハンドラーに戻しています。
3. **case8 の連続ブロック**:550×4800/48000 = 55 周期ちょうどです。`OFFSET` を 0 に戻して同じ先頭 4800 フレームを繰り返すので、位相はつながります。4800 フレームの空きを待つ処理(`4800 -1 P @ PCM-WAIT`)は、4800 が容量以下なので `InvalidNumber` になりません(`src/core/words_pcm.zig:91`)。空きを待ってから送るため、`SEND` の中の1フレーム待ちはすぐに戻り、全量が空くまで待つことはなくなりました。
