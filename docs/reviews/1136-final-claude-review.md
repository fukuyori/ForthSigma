## N1 の確認
- **制御値と周波数（`verify-sid.py:217-220`）:** 制御値は 129/23/67 です。129 は noise と GATE だけで、SYNC は立っていません。23 は三角波・RING・SYNC・GATE、67 はパルス・SYNC・GATE です。周波数は FFFF/7FFF/5555 で、PW は 2048 です。指摘した内容に合っています。
- **声1の SYNC と RING:** 声0は FREQ=FFFF なので、約256 clock ごとに MSB が立ち上がります。声1の SYNC は、そのたびに位相を0に戻します。声0の MSB は時間の約半分 high になるので、声1の RING の XOR が働きます。
- **声2のパルス:** 5555 は SYNC で戻されないので、位相が全範囲を回ります。PW=2048 に対して、high と low の両方が出ます。
- **カバレッジの検査（`:106-111`、`:231`）:** pulse の high と low、RING 元の MSB の high を数え、混在条件と 8kHz 条件で、どれも0回でないことを assert しています。
  - 8kHz 条件で書き換わるのは D400、つまり声0の周波数の下位バイトだけです。周波数は FF00 以上のままなので、同じ状態が保たれます。
- **3声全 noise 条件（`:227`）:** 制御値は 130 か 131 で、noise と SYNC が立ちます。周波数は3声とも FFFF です。混在条件とは別の条件のまま残っています。
