## (2) 残る重大・高の設計矛盾

重大はありません。高が1件あります。

**高: ワーカーの許可語検査に、静的にコンパイルされた呼出しが含まれていません**
- **根拠**:
  - 詳細設計11.3は、許可検査を「実行の入口と動的な呼出し先」に適用すると書いています。
  - 一方、組込み語はコードの中でOpとして直接実行されます。短い定義は呼出し元へ展開されます(`forth.zig:337-340`、`image_restore.zig:80-81` の `specializeCall`・`inline_calls.restore`)。
  - そのため、許可した入口語の内部で禁止語を直接コンパイルしていると、入口とEXECUTEの検査だけでは止められません。R02の隔離が成り立たなくなります。
- **修正案**: 11.3と監査表の「組込み語の間接呼出し」の行に、次のどちらかを方式比較の項目として書き加える。
  - (i) 投入時に、入口から到達するコードを展開分も含めて静的に走査する。
  - (ii) worker専用ループで、Opごとに許可を検査する。

  (ii)はR01の(b)案と同じ経路にまとめられます。
