# 652 Mac実機の受け入れ手順

状態：未実施。1122を未完了に残す。640の1111・646の1116も別の未完了項目。
クロスコンパイル成功は以下の実機合格を意味しない。

1. Macで現在のソース・Zig 0.17.1を使い、`zig build`と`zig build test`を実行する。実行ファイル、OS/CPU、Git状態とログを記録する。
2. `python3 tests/scripts/verify-execution-control.py zig-out/bin/sigma`を実行する。専用PTYで予算・入れ子・THROW・LOAD後の制限、Raw文字/貼付け/未完成ESC/UTF-8、NS/Cooked KEY中断、mode復元を確認する。すべてのassertと終了コードを確認しstdoutのJSONを保存する。
3. 実際のTerminal.app等で短い無限ループをEXEC-LIMITEDに渡し、Ctrl+Cが-28としてCATCHへ届くこと、通常文字・日本語・矢印・貼付け中の値3の扱い、終了後のechoと改行入力を確認する。使用端末とキー操作を記録する。
4. debugなしとextensionなしを別にビルドし、`EXEC-LIMITED`が辞書/HELPにないこと、画像の保存/復元・既存EXTENSION語が動くことを確認する。
5. NS・音声待機（音声deviceがある場合）・入力待ちの入れ子と中断後の再実行を確認する。OS呼出しの強制中断や20ms保証、継続再開は受け入れ対象に含めない。

Rawキューが満杯の場合は、その後ろのCtrl+Cを検出できないことがある。文字を捨てない方針として了承済み。OS信号経由の中断と区別する。失敗時は端末mode・信号所有のログを採り、推測だけで修正しない。

合格後は実行ログ・ソース指紋を実装記録へ追記し、タイトル/親子関係を再照合して1122を完了する。コミット・タグ・pushは別の明示依頼が必要。
