# 613 詳細設計レビューへの対応

作成日：2026-11-19
対象：[Claude Codeの初稿レビュー](CORE_EXTENSION_CLAUDE_REVIEW.md)。Claude Code 2.1.327、セッション50584ef4-de2a-4e63-a8e2-e1046942c02e、約600秒・50ターン。読み取り専用で実施。ソース照合の範囲と未確認箇所はレビュー原文に保持する。

## 評価

初稿は「このままの承認はできない」と評価された。20件のうち、通常ビルドの取消しと独立VMの隔離が重大事項。設計上の欠落と実装時の確定事項を分けて反映した。指摘への文書対応は、実装が成立した証拠やClaude Codeの再承認を意味しない。

## ソースとの追加照合

- forth.zigのhaltedは非atomicで、CATCHを再開し0を積む経路がある。取消し用の共有フラグには使わない。
- Storageとは別にStateへ辞書配列やホスト参照が含まれる。State直下167フィールドを列挙し、初期化を既定とする監査表を作成した。再帰監査の完了ではない。
- image_restoreのimage_generationは復元時に増える。通常の変数更新を検出する一般的な辞書世代として使わない。
- graphics_imagesの画素取得はrgb_mask、初期画像はopaque_black、色キーはRGB判定。premultiply済み保存への一括置換を設計の前提から外した。
- ASYNC_OVERVIEWにはZigネイティブジョブのみとする初期案がある。元のワーカーVM案と合わせて方式比較へ戻した。

## Claude Codeによる再確認と追加対応

再確認はClaude Code 2.1.327、セッションf64e90cd-d198-4f5f-994b-51d233dd30da、約92秒・13ターン。原文は[再確認結果](CORE_EXTENSION_CLAUDE_FOLLOWUP.md)。評価は「重大なし・高1件」、方式選択ゲートはおおむね妥当。原文の指摘へ追跡用IDを以下で付与した。

| ID | 区分 | 追加対応 |
|---|---|---|
| F01 | 高 | 許可検査に静的呼出し・直接builtin Op・インライン展開後の命令を含め、到達コード走査とworker専用実行時検査の二段案を追加。動的行先だけの検査にしない |
| F02 | 採用ゲートの補足 | 1049の試作前に最小許可語の到達先を監査し、1053で隔離が不成立ならForth VM公開を止め方式比較へ戻す |
| F03 | 中 | addressesを再構成へ分類。Storage容量とpreflightのm/l・builtin_count一致、ヒープ検査を明記 |
| F04 | 中 | 停止不能時も、独立した資源の子終了要求・音停止・端末復元を明示的に試みる。共有参照の解放・ロック待ちとは分ける |
| F05 | 低 | 900の信号所有最小実装は抽象・新経路の仲介と差替え試験まで。既存sigaction/maskの一括移行は未実施と区別 |
| F06 | 低 | workerモードを652の数える経路とは別文脈で、入れ子の実行にも引き継ぐ案を追加 |

F01〜F06はソースと照合して文書へ反映した。反映後の三度目の外部レビューは実施していない。初稿の重大2件と再確認の高1件は設計の記述を補完したものであり、取消し・隔離の実装が検証できたとは扱わない。

## 残る採用判断

通常ビルドへworker専用ループを追加する解釈、ジョブ限定かForth VMか、スナップショットの形式、OS語の所属などは[判断記録](CORE_EXTENSION_DESIGN_DECISIONS.md)の条件で確定する。実装前の詳細化・試作を担当するタスクを明示しており、質問を省くために決定済みとはしない。
