# FORTH/Σ移植の決定事項と保留事項

資料に明記された仕様、Zig移植で選んだ動作、資料だけでは決められない点を分けて記録します。ソースページの対応は[FORTH/Σ仕様書](SPEC.md)、実装上の値と未実装機能は[実装ノート](IMPLEMENTATION.md)を参照してください。

## 方針の変更（2026-10-28）

利用者の指示により、Gforthの挙動に近づけ、教材ForthBasicMasterのサンプルが動くことを目標にしました。作業は6段階に分け、段階1（コアの変更）、段階2（浮動小数点）、段階3（文字列・数値書式）を実装済みです。意味が衝突する部分はGforthに合わせ、衝突しないFORTH/Σ固有のワードは残しています。GforthはGPLv3のため、挙動だけを参照し、コードは移植していません。

| 段階 | 内容 | 状態 |
| --- | --- | --- |
| 1 | 64ビットセル、1 MiBメモリ、真=-1、床関数除算、全文字の名前照合、TYPE ( addr u )、基本標準ワード | 実装済み |
| 2 | 浮動小数点スタックとF系ワード（教材Level 17の範囲） | 実装済み |
| 3 | 文字列・数値書式（S"、<# #>、倍長整数など） | 実装済み |
| 4 | ローカル変数 | 未実装 |
| 5 | 例外・ファイル・動的メモリ（Level 14の `$!` などの動的文字列を含む） | 未実装 |
| 6 | 語彙・条件付きコンパイル | 未実装 |

## 移植版で選んだ動作

| 項目 | 現在の決定 | 理由・影響 |
| --- | --- | --- |
| 名前の大小文字 | ASCII英字は大小を区別しない。 | Gforthと同じ。資料では確定しない。 |
| 数値入力 | 基数2〜36、小文字も受け付ける。`$` `#` `&` `%` 接頭辞と `'c'` を認識する。 | Gforthの数値認識に合わせた。 |
| 浮動小数点リテラル | 基数が10のときだけ、`e`/`E` を含むトークンを浮動小数点数とする。 | Gforthの `rec-float`。 |
| 倍長整数リテラル | 数字の間のどこかに `.` を含む整数は倍長整数（128ビット）。`1.5` は15、`12345.123` は12345123。`DPL` は未実装。 | Gforthの `s>unumber?`（`kernel/int.fs`）。 |
| 倍長整数の格納順 | スタックでは上位セルが上。`2!` は上位セルを低いアドレスに格納する。 | Forth 2012。教材Level 18の `BIGNUM 2!` の例と一致する。 |
| 数値書式の保持領域 | `<#` `<<#` の保持領域は1000H〜1FFFH（下向きに伸びる）。`<<#` の入れ子は16段まで。あふれ・対応しない `#>>` は `PICTURED NUMERIC OUTPUT ERROR !`。 | Gforthの `holdptr`/`holdend`（`kernel/nio.fs`）。領域の位置と大きさはポータブル版の判断。 |
| PAD | 2000Hからの4096バイト。 | Gforthは84バイト以上を保証。位置と大きさはポータブル版の判断。 |
| 実行時のS" | 解釈中の `S"` `S\"` は3000Hからの256バイト×4個のバッファを順に使う。定義内ではデータ領域にコンパイルする。最大255バイト。 | 同時に4個まで有効。FORTH/Σの `"` と `."` は127バイトのまま。 |
| エスケープ文字列 | `S\"` `.\"` は `\a \b \e \f \l \m \n \q \r \t \v \z \" \\ \xHH` を解釈する。`\n` はLF。 | Gforthの `S\"`。 |
| KEY? | コマンドラインでは1バイト先読みで判定する。対話端末では入力を待ち、パイプ入力では終端で偽を返す。 | 標準入出力だけで実装するため。端末を非ブロックで調べる処理は未実装。 |
| 浮動小数点の表示 | `F.` は有効15桁・指数なし・末尾空白。`F.S` は有効14桁の `e` 表記。無限大・NaNは `infinity` `-infinity` `NaN`。 | Gforthの `f.`、`f.s`、`engine/support.c` の `represent`。教材の出力例とは一部異なる。 |
| 浮動小数点のゼロ除算 | IEEE 754に従い無限大またはNaN。エラーにしない。 | Gforthの `f/` はCの除算 `r3 = r1/r2` をそのまま使う（`prim`）。浮動小数点例外を有効にした環境のGforthの挙動は未確認。 |
| F>S | 0方向へ切り捨て。NaNは0、範囲外は最小値・最大値。 | 範囲外の扱いはポータブル版の判断。 |
| セル演算 | 加算・減算・乗算は64ビットで折り返す。最小値÷-1は最小値、余り0。 | ホスト環境に依存させない。 |
| SWAB | セル全体の8バイトを反転する。 | 16ビット時代の意味を64ビットへ広げた移植判断。資料に根拠はない。 |
| C. | 下位8ビットを符号なしで表示し、末尾に空白。 | ゼロ埋めなしの方針に合わせた。 |
| ループ枠 | ループ枠は利用者のリターンスタックと分離する。 | `I` と `R@` は別の値になる。 |
| +LOOP境界 | 符号付き増分の方向に終値を横切ったら終了する。 | Z80リストの比較部分を確定できないため選んだ移植規則。 |
| ?DO, J, K | ?DOは同値範囲を飛ばす。J/Kは外側ループ添字を返す。 | 便利な追加機能。 |
| <BUILDS/DOES>, CREATE | <BUILDSとCREATEは入力ストリームから作成語名を読み、DOES>から定義末尾までの操作列を作成語に結び付ける。 | 誌面の2ARRAY例を踏まえて、Z80コードではなく操作列で実装。 |
| 定義用語の辞書位置 | 作成した語は、その時点のデータ領域位置を保持する。FORGETは後続の作成語も削除し、データ領域を回収する。 | 既存の辞書とデータ領域管理に合わせた移植動作。 |
| 実行トークン | ホスト側の辞書インデックスを使う。 | Z80機械語アドレスを持ち込まずEXECUTEを提供するため。 |
| 利用者定義語の優先 | 利用者が定義した語は、同名の組み込み語や構文語（VALUE、TOなど）より優先する。 | Gforthで再定義した語が優先されるのに合わせた。 |
| 辞書イメージ | 形式を `SIGIMG02` に変更。16ビット版の `SIGIMG01` は読み込めない。 | セル幅・メモリ量・操作列の形式が変わったため。 |
| 入力行・容量 | 入力4096バイト、名前255バイト、データ・リターン・浮動小数点スタック各1024、辞書1024語、コード8192操作。 | ポータブル版の現行上限。 |

## 上限・境界・エラー復帰

- データ領域は4000Hから論理メモリ末尾（100000H）までを割り当て可能とします。末尾を超えるALLOT、変数、配列、文字列、カンマ、Cカンマ、Fカンマは失敗し、データ領域ポインタを進めません。負のALLOTは4000Hまで戻せます。
- セル・浮動小数点数は8バイトのリトルエンディアンで読み書きします。アドレスが0未満、または読み書きが論理メモリ末尾を越える場合は `INVALID MEMORY ADDRESS !` になります。アドレスの折り返しはしません。配列アクセスは要素数を検査しません。
- スタックのアンダーフロー／オーバーフロー、領域超過、辞書／コード超過、ゼロ除算はエラーです。制御ネスト超過はNESTING ERRORとして報告します。エラー報告時にデータ・リターン・浮動小数点・ループ・制御スタックを初期化します。
- コンパイル中のエラーは、作成中のワード、追加コード、当該定義中に確保したデータ領域を巻き戻します。既に完了した定義は残します。トップレベルのALLOT失敗では、割り当て位置は失敗前の値を保ちます。
- FORGETは指定語以後の辞書語をすべて削除し、削除対象内の最初のコンパイル済み定義までコード位置を戻します。データ位置も指定語の割り当て前へ戻し、その後の定義で領域を再利用します。

## 資料だけでは確定できない点

| 項目 | 現状 | 次に判断する条件 |
| --- | --- | --- |
| NORの論理定義 | 解説文とZ80リスト／マニュアルの記述が一致しない。現行版はNOT(a OR b)を実装。 | 誌面画像の再確認、または対象とする版の特定。 |
| 1-の原版での位置付け | サンプルにはあるが、語一覧での扱いが一貫しない。現行版には実装済み。 | 機種版ごとの完全な語一覧を特定。 |
| 負の+LOOP | 終値との比較規則を判読できない。現行版は符号付き方向判定を採用。 | 対象版のソースとCPU条件分岐を再読解。 |
| 版間の共通範囲 | SORD M200、CP/M、PC-8001の差を全ワードについて整理できていない。 | 対象とする原版を明示し、各版の資料を分離して照合。 |

保留事項は推測で確定しません。実装の現行動作は選択済みであっても、資料から確認できた原版仕様とは区別して扱います。
