# FORTH/Σ移植の決定事項と保留事項

資料に明記された仕様、Zig移植で選んだ動作、資料だけでは決められない点を分けて記録します。ソースページの対応は[FORTH/Σ仕様書](SPEC.md)、実装上の値と未実装機能は[実装ノート](IMPLEMENTATION.md)を参照してください。

## 方針の変更（2026-10-28）

利用者の指示により、Gforthの挙動に近づけ、教材ForthBasicMasterのサンプルが動くことを目標にしました。作業は6段階に分け、段階1（コアの変更）、段階2（浮動小数点）、段階3（文字列・数値書式）を実装済みです。意味が衝突する部分はGforthに合わせ、衝突しないFORTH/Σ固有のワードは残しています。GforthはGPLv3のため、挙動だけを参照し、コードは移植していません。

| 段階 | 内容 | 状態 |
| --- | --- | --- |
| 1 | 64ビットセル、1 MiBメモリ、真=-1、床関数除算、全文字の名前照合、TYPE ( addr u )、基本標準ワード | 実装済み |
| 2 | 浮動小数点スタックとF系ワード（教材Level 17の範囲） | 実装済み |
| 3 | 文字列・数値書式（S"、<# #>、倍長整数など） | 実装済み |
| 4 | ローカル変数 | 実装済み |
| 5 | 例外・ファイル・動的メモリ（Level 14の `$!` などの動的文字列を含む） | 5a（THROWと主なファイル語）、5b（ALLOCATEと動的文字列）を実装済み。CATCHは未実装 |
| 6 | 語彙・条件付きコンパイル | 未実装 |

## 上限・境界・エラー復帰

- データ領域は4000Hからヒープの先頭（100000H）までを割り当て可能とします。末尾を超えるALLOT、変数、配列、文字列、カンマ、Cカンマ、Fカンマは失敗し、データ領域ポインタを進めません。負のALLOTは4000Hまで戻せます。
- セル・浮動小数点数は8バイトのリトルエンディアンで読み書きします。アドレスが0未満、または読み書きが論理メモリ末尾を越える場合は `INVALID MEMORY ADDRESS !` になります。アドレスの折り返しはしません。配列アクセスは要素数を検査しません。
- スタックのアンダーフロー／オーバーフロー、領域超過、辞書／コード超過、ゼロ除算はエラーです。制御ネスト超過はNESTING ERRORとして報告します。エラー報告時にデータ・リターン・浮動小数点・ループ・制御スタックを初期化します。
- コンパイル中のエラーは、作成中のワード、追加コード、当該定義中に確保したデータ領域を巻き戻します。既に完了した定義は残します。トップレベルのALLOT失敗では、割り当て位置は失敗前の値を保ちます。
- FORGETは指定語以後の辞書語をすべて削除し、削除対象内の最初のコンパイル済み定義までコード位置を戻します。データ位置も指定語の割り当て前へ戻し、その後の定義で領域を再利用します。

## 資料だけでは確定できない点

| 項目 | 現状 | 次に判断する条件 |
| --- | --- | --- |
| NORの論理定義 | 解説文とZ80リスト／マニュアルの記述が一致しない。現行版はNOT(a OR b)を実装。 | 誌面画像の再確認、または対象とする版の特定。 |
| 1-の原版での位置付け | サンプルにはあるが、語一覧での扱いが一貫しない。現行版には実装済み。 | 機種版ごとの完全な語一覧を特定。 |
| 負の+LOOP | 終値との比較規則を判読できない。現行版は符号付き方向判定を採用。 | 対象版のソースとCPU条件分岐を再読解。 |
| 版間の共通範囲 | SORD M200、CP/M、PC-8001の差を全ワードについて整理できていない。 | 対象とする原版を明示し、各版の資料を分離して照合。 |

保留事項は推測で確定しません。実装の現行動作は選択済みであっても、資料から確認できた原版仕様とは区別して扱います。
