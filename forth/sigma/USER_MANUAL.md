# FORTH/Σ Zig版 ユーザーマニュアル

この文書は、現在のZig移植版の使い方を説明します。誌面に掲載された機能でも、現在の実装にないものは含めていません。FORTH/Σの仕様整理は[仕様書](SPEC.md)、各語の掲載状況は[互換性一覧](COMPATIBILITY.md)を参照してください。

## 起動と入力

リポジトリのルートで次のようにビルド・起動します。

```powershell
zig build
.\zig-out\bin\sigma.exe
```

起動すると対話プロンプトになります。入力行を処理すると、成功時には `OK` が表示されます。たとえば次の入力は、12の二乗を表示します。

```forth
: SQUARE DUP * ;
12 SQUARE . CR
```

結果の数値は `144` です。`.` は数値の後ろに改行を付けないため、改行が必要なときは `CR` を続けます。複数行のForthソースは標準入力から渡せます。

```powershell
Get-Content .\examples\demo.fs | .\zig-out\bin\sigma.exe
```

`BYE` で処理系を終了します。未定義語などのエラーが起きた場合は診断を表示し、次の入力行へ戻ります。

## ワードの定義と辞書

利用者定義語は `: 名前 ... ;` で作ります。ワード名の照合はASCII英字の大文字・小文字を区別しません。既存名を再定義すると警告が出ますが、新しい定義が優先されます。同じ名前の古い定義も辞書内に残ります。

```forth
: DOUBLE 2 * ;
21 DOUBLE . CR
```

`WORDS` は現在の辞書の登録語を表示します。`FORGET 名前` は指定語と、それより後に登録された利用者定義語を削除します。そのため、後から同名定義を追加したあと新しい方を `FORGET` すると、古い定義が再び使われます。削除対象より後に定義した別の語も一緒に削除される点に注意してください。

## 変数・定数・配列

```forth
VARIABLE COUNT
10 COUNT !
COUNT @ . CR
42 CONSTANT ANSWER
ANSWER . CR
4 ARRAY CELLS
```

`VARIABLE`（別名 `VAR`）は変数を作り、`CONSTANT`（別名 `CONST`）はスタック先頭の値を定数として登録します。`ARRAY` はスタック先頭の要素数を受け取り、その次の入力語を配列名として登録します。配列添字は0からです。`A@`／`A!`などメモリ操作ではアドレスと範囲を利用者が管理してください。

## 制御構造

制御構造は定義内で使います。条件はスタック先頭を調べ、0を偽、0以外を真として扱います。

```forth
: ABS-VALUE DUP 0 < IF MINUS THEN ;
: COUNT-UP 5 0 DO I . LOOP ;
```

利用できる構造は `IF ... ELSE ... THEN`、`BEGIN ... END`、`BEGIN ... WHILE ... REPEAT`、`DO ... LOOP`、`DO ... +LOOP`、`LEAVE`です。拡張語 `?DO` は開始値と終値が等しい場合に本体を実行しません。`I`、`J`、`K` は内側からそれぞれ1段目、2段目、3段目のループ添字を返します。

## 入出力と基数

| 用途 | ワード | 説明 |
| --- | --- | --- |
| 数値出力 | `.`, `C.` | スタック先頭の数値、または下位8ビットを数値として表示します。`.`は末尾に改行を付けません。 |
| 文字出力 | `ECHO` | スタック先頭の下位8ビットを文字として出力します。 |
| 文字列出力 | `TYPE`, `."..."` | `TYPE` は文字数とアドレスを受け取り、文字列を出力します。` ."..." ` は移植版の拡張です。 |
| 改行・空白 | `CR`, `SPACE`, `SPCES` | 改行、1個の空白、スタックで指定した数の空白を出力します。`SPCES`は実装上の綴りです。 |
| 数値入力 | `INPUT` | 端末から数値を1個読み取ってスタックへ積みます。 |
| 基数変更 | `HEX`, `DEC`, `OCT` | 数値入出力の基数を16進、10進、8進に切り替えます。初期値は10進です。 |
| 基数参照 | `BASE` | 基数値を保持する論理メモリのアドレスをスタックへ積みます。 |

誌面由来の `"..."` は定義内でコンパイルして使う文字列語です。`TYPE`へ渡すときは文字数、アドレスの順にスタックへ積みます。

## 辞書の保存と単独実行ファイル

この移植版の `SAVE` と `LOAD` は利用者定義語の辞書イメージを扱います。誌面のエディットバッファ操作とは異なります。

```forth
SAVE words.sigma
LOAD words.sigma
```

`LOAD` は保存した利用者定義語を現在の辞書の後ろに追加します。同名語は読み込んだ新しい定義が優先されます。

`SAVESYS` は、現在の辞書・コンパイル済み定義・データを含む、実行中環境向けの単独実行ファイルを作ります。

```forth
SAVESYS demo.exe
```

生成したファイルは引数なしで起動すると、その辞書を持つ対話プロンプトを開きます。引数がある場合は、引数を連結した文字列をForth入力として1回実行して終了します。生成物は作成元と同じ実行環境向けです。

## 登録済みワード一覧

次の表は、起動時に辞書へ登録され、`WORDS`で表示される組み込みワードです。`VARIABLE`、`:`、`IF`などの構文語は別途、次の「構文・定義形式」に記載します。利用者が定義した語は、この表には含まれません。

| 分類 | 登録語 |
| --- | --- |
| スタック操作 | `DROP`, `DUP`, `SWAP`, `OVER`, `ROT`, `>R`, `R>` |
| 算術 | `+`, `-`, `*`, `/`, `MOD`, `/MOD`, `MINUS`, `ABS`, `MAX`, `MIN`, `1-` |
| 比較・論理・ビット | `=`, `<>`, `<`, `>`, `<=`, `>=`, `NOT`, `0=`, `AND`, `OR`, `XOR`, `COM`, `NAND`, `NOR`, `SWAB` |
| メモリ・配列 | `@`, `!`, `,`, `C,`, `C@`, `C!`, `+!`, `1+!`, `1-!`, `OSET`, `?`, `A@`, `A!`, `HERE`, `ALLOT` |
| ループ関連 | `I`, `J`, `K`, `LEAVE` |
| 入出力 | `.`, `C.`, `ECHO`, `CR`, `SPACE`, `SPCES`, `TYPE`, `INPUT` |
| 基数 | `HEX`, `DEC`, `OCT`, `BASE` |
| 定義補助・辞書・実行 | `<BUILDS`, `WORDS`, `BYE`, `LOAD`, `SAVE`, `SAVESYS`, `EXECUTE` |

組み込み語は起動時点で **71語** 登録されています。利用者定義語や別名はこの数に含みません。

### 構文・定義形式

以下はForth入力で使える構文ですが、`WORDS`が列挙する組み込み辞書語ではありません。

| 種類 | 語・形式 | 説明 |
| --- | --- | --- |
| 定義 | `: 名前 ... ;` | コンパイル済みの利用者定義語を作ります。 |
| 定義・削除 | `VARIABLE 名前`, `VAR 名前`, `CONSTANT 名前`, `CONST 名前`, `FORGET 名前` | 変数・定数を登録し、または辞書末尾までを削除します。 |
| 配列 | `要素数 ARRAY 名前` | 要素数をスタックから取り、配列を登録します。 |
| コンパイル制御 | `[`, `]`, `' 名前` | コンパイル中断／再開、実行トークンの取得に使います。 |
| 条件 | `IF`, `ELSE`, `THEN` | 条件分岐を定義します。 |
| ループ | `BEGIN`, `END`, `WHILE`, `REPEAT`, `DO`, `?DO`, `LOOP`, `+LOOP` | 定義内の制御構造を指定します。`?DO`は移植版の拡張です。 |
| 作成語 | `DOES>` | `<BUILDS`で作成した語へ実行動作を結び付けます。 |
| 文字列 | `"..."`, `."..."` | コンパイル時文字列と、移植版の文字列出力拡張です。 |

## 実装していない機能

現在は `EDIT`、`LIST`、エディットバッファ版の `LOAD`／`SAVE`、CP/Mファイル操作、PC-8001のモニター機能、`MCODE`やZ80機械語実行に対応していません。Z80をエミュレートする処理系ではありません。誌面掲載語の全てが実装済みという意味ではありません。詳しくは[互換性一覧](COMPATIBILITY.md)を参照してください。
