# FORTH/Σ for Zig

FORTH/Σ（フォース・シグマ）の言語コアを、Zigで動くネイティブな移植版として実装するプロジェクトです。1982年の誌面に掲載されたFORTH/Σの説明とZ80ソースリストを仕様調査の資料として使っています。Z80の命令や機械語を実行・エミュレートするものではありません。

## 現在の実装

- 16ビットセルと64 KiBの論理メモリを使います。
- 対話入力、辞書検索、数値入力、ワード定義とコンパイルに対応しています。
- スタック操作、算術・比較・論理演算、メモリ操作、変数・定数・配列を使えます。
- IF ... ELSE ... THEN、BEGIN ... END、BEGIN ... WHILE ... REPEAT、DO ... LOOP、DO ... +LOOP、LEAVEを使えます。
- HEX、DEC、OCTによる基数変更、数値・文字・文字列の出力に対応しています。
- WORDS、FORGET、BYEを対話用ワードとして提供します。
- 辞書、コンパイル済み定義、メモリ、入出力をホスト環境から分離し、他のOS・CPUへ移植しやすい構成にしています。

対応ワードと移植上の判断は[実装ノート](forth/sigma/IMPLEMENTATION.md)、資料から整理した言語仕様は[FORTH/Σ仕様書](forth/sigma/SPEC.md)を参照してください。実装は開発中であり、誌面の全ワードや機種固有機能には対応していません。

現時点では、<BUILDS/DOES>、LIST、ソースファイルやエディタの操作、CP/Mのファイル機能、PC-8001のモニタ機能、Z80機械語を使うワードには対応していません。

## ビルドと実行

Zigをインストールした環境で、リポジトリのルートから実行します。

    zig build
    ./zig-out/bin/sigma.exe

Linux/macOSでは、生成されたzig-out/bin/sigmaを実行してください。別のZigターゲットを指定する場合はzig build -Dtarget=<triple>を使います。

例:

    : SQUARE DUP * ;
    12 SQUARE .

## 標準Forthとの違い

この実装は**ANS Forth／Forth 2012準拠を目標とする処理系ではありません**。1982年のFORTH/Σ資料にある言語仕様を移植しつつ、ポータブルな実行環境に合わせた追加判断を含みます。したがって、標準Forthのプログラムをそのまま実行できる互換性はありません。

| 項目 | FORTH/Σ資料と現在の移植版 | Forth 2012 Core |
| --- | --- | --- |
| セル幅 | 16ビットとして扱います。 | セル幅は処理系に依存します。16ビットであることだけで標準違反とはなりません。 |
| 真偽値 | 0が偽、1が真です。 | 偽は全ビット0、真は全ビット1です。 |
| TYPE | スタックは( u addr -- )で、アドレスが先頭です。 | ( c-addr u -- )で、文字数が先頭です。 |
| 文字列 | 資料由来の"..."はコンパイル時のワードで、長さの後にアドレスを積みます。 ."も移植版の便宜的な拡張として提供します。 | 標準のS"はコンパイル時に実行時の文字列アドレスと長さを返します。 |
| 数値表示 | .は末尾に空白を付けず、16進数を4桁、8進数を6桁で表示します。 | 表示書式は標準の数値出力ワードの仕様に従い、Sigma固有の固定桁書式とは異なります。 |
| 制御構造 | 資料にあるEND、LEAVE等を含みます。移植版は?DO、J、Kも追加しています。 | 標準Coreのワードセットと制御フロー規則に従います。 |

標準側の定義は[Forth 2012 Standard](https://forth-standard.org/standard/index)を参照してください。Sigma側の個々の挙動と移植上の追加判断は、上記の仕様書と実装ノートに記録しています。
